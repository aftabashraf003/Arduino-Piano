# 🎹 Arduino Piano

A simple Arduino Piano project using **8 push buttons** and a **passive buzzer**. Each button plays a different musical note, allowing you to create simple melodies.

## Components
- Arduino Uno
- 8 Push Buttons
- Passive Buzzer
- Breadboard
- Jumper Wires

## Pin Connections

| Pin | Note |
|-----|------|
| 12 | C4 |
| 11 | D4 |
| 10 | E4 |
| 9  | F4 |
| 7  | G4 |
| 6  | A4 |
| 5  | B4 |
| 4  | C5 |
| 8  | Buzzer |

## Files
- `Arduino_Piano.ino` – Main Arduino program
- `pitches.h` – Musical note definitions
